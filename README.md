# Home Assistant apps

| App | What it does |
|---|---|
| [Recipe to Grocery List](recipe_to_list/DOCS.md) | Send recipe links to a Telegram bot, review a merged checklist, add the items to OurGroceries (or any HA to-do list). |

## Install
1. In Home Assistant go to **Settings → Apps → Install app**, open the **⋮** menu, and choose **Repositories**.
2. Add this repository's URL.
3. Find **Recipe to Grocery List** in the list and install it.

Updates appear automatically when the app's `version` in `config.yaml` changes.
